FOURIER SERIES SIGNAL ANALYZER

Aplikasi untuk menganalisis sinyal menggunakan Deret Fourier.

Cara Menjalankan:
1. Aktifkan virtual environment.
2. Pastikan library sudah terpasang.
3. Jalankan perintah:
   streamlit run app.py

Aplikasi akan terbuka melalui browser.

Library:
- NumPy
- Matplotlib
- Streamlit
